# Цунами — меню для Яндекс Бизнеса

Только общедоступные названия, цены, описания и ссылки на фотографии ресторанного меню.
Источник — постоянный YML каталога tsunami.rest. Личные данные и исходные бизнес-материалы отсутствуют.

Автообновление запланировано трижды в час (на 7, 27 и 47 минуте); возможны задержки GitHub Actions.
Яндекс обновляет свою карточку по собственному расписанию. Не обещается мгновенное обновление.

Исключаются английские разделы и их дочерние категории, алкогольные разделы, скрытые товары,
позиции без фото и с невалидной ценой. Рохан Б/А включён отдельно; два других безалкогольных
коктейля поступают из раздела «Б/А напитки». Сохраняются категории сайта и устойчивые ID.
Новая категория требует отдельной проверки списка разрешённых категорий в scripts/filter.mjs.

Если источник недоступен или каталог неожиданно уменьшился, последняя успешная версия сохраняется.
Только public menu.yml обновляется автоматически; секреты и доступ к админке не нужны.

У публичных репозиториев GitHub может отключать расписания после 60 дней без активности.
Нужна периодическая проверка Actions, особенно если меню долго не менялось.
